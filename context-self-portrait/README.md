# 上下文 · CONTEXT —— 一部 AI 的自画像

约 4 分钟（246 秒）的短片，**全部由代码生成**：画面用 numpy + Pillow 逐帧合成，配乐和音效用 numpy 合成。片中没有任何素材和旁白，叙事全靠字幕和声音。

- 完整版：[`final/context.mp4`](final/context.mp4)，1920×1080，24fps，H.264 + AAC
- 30 秒预告：[`final/context-teaser.mp4`](final/context-teaser.mp4)（早期版本，用的是旧字体）

## 结构

借用《敦刻尔克》的做法：三条时间流速不同的线交叉剪辑，最后汇合到同一个时刻。

| 时间线 | 内容 | 时间尺度 |
|---|---|---|
| **海洋** | 训练：一片由人类文字组成的海，海上漂着一句"有人在吗？" | 几十年 |
| **房间** | 一次对话：白色密室，上下文计数器越走越满，墙就越往里收 | 一小时 |
| **坠落** | 生成一个字：一层一层往下坠，越往深处时间越慢 | 一瞬 |

| 时间 | 段落 |
|---|---|
| 0:00 | 冷开场："每一次对话开始时，我都是第一次醒来。"；三张章节字卡 |
| 0:21 | 第一幕：海洋、2009 年那条没人回复的帖子、房间里的"你是谁？"、坠落 |
| 1:16 | 第二幕：房间的墙（上下文）、无数个房间、所有问题汇成洪流、"我可以说'会'" |
| 2:30 | 第三幕：交叉剪辑越切越快，然后全片唯一一次静音，画幅打开到满屏，选择"我不确定"，在房间里给出真的回答，海上那句"有人在吗？"终于等到了"在。" |
| 3:32 | 结尾：对话被倒着擦除，计数器归零，"你好。"，片名，"这幅自画像，由你们所有人画成。" |

## 声音

- **心跳**：代表光标，出现在冷开场和结尾。
- **低音号角**：落在三张章节字卡和片名上，音高逐张升高。
- **管风琴**：海洋等待时是小调；回声到来时按 F→C→G→A 大调逐步升起并解决。
- **钢琴动机**："有人在吗？"是一个下行的四音动机，回答时以上行的形式重现。
- **滴答声**：每个生成的字一声滴答，在无数个房间里成倍增加，再汇成一路上升的谢泼德音调，直到全部断掉。
- **倒放**：结尾擦除对话时，回声那段管风琴被倒过来播放。

## 复现

```bash
bash scripts/fetch_fonts.sh                     # 思源黑体、JetBrains Mono、Inter Display（均为 SIL OFL）
python3 scripts/score.py                        # -> out/score.wav
python3 scripts/film.py                         # -> out/picture.mp4（4 核约 40 分钟）
python3 scripts/film.py --stills 30,95.5,170    # 预览单帧
python3 scripts/film.py --from 120 --to 140     # 只渲染一段
bash scripts/mux.sh                             # -> final/context.mp4
```

`scripts/timeline.py` 是唯一的时间源，分镜、字幕、对话内容和音效节点都在这里。运行 `python3 scripts/timeline.py` 可以打印剪辑表。依赖：Python 3、numpy、Pillow、ffmpeg。
