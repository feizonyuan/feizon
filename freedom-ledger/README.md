# 自由账本（Freedom Ledger）

一个原创的单人网页理财模拟游戏。玩家每月领工资、付账单、抽事件卡并做决策，
目标是让**被动收入超过月支出**。

游戏使用通用的会计原理（收益表、资产负债表、现金流），
规则、卡牌、数值和界面均为原创，不复刻任何现有的商业桌游。

## 状态

目录刚建立，尚无代码。下面是实现计划。

## 设计要点

- **单人、短局**：一局 15–20 分钟，一回合等于一个月。
- **本土化**：国内的职业、薪资、房贷、公积金、指数基金、副业。
- **自动记账**：玩家只做决策，两张报表自动更新，并显示每笔钱的流向。
- **有真实风险**：失业、加息、房屋空置、现金断流会导致破产。
- **胜负条件**：被动收入 ≥ 月支出为胜；现金为负且无法变现或借款为负。

## 技术选型

- 纯静态网页：HTML + CSS + 原生 ES 模块，无构建步骤，无运行时依赖。
- 规则引擎是纯函数（`状态 + 动作 → 新状态`），与界面分离，可用 `node --test` 测试。
- 随机数使用可设种子的生成器，保证对局可重放、测试可复现。
- 进度存在浏览器 `localStorage`。

## 目录规划

```
freedom-ledger/
  index.html
  src/
    engine/     规则引擎：状态、回合、结算、胜负判定
    data/       职业与卡牌数据（JSON）
    ui/         界面渲染与交互
  tests/        引擎单元测试与整局模拟测试
```

## 实现步骤

1. **引擎核心**：玩家状态、收益表与资产负债表的计算、月度结算、胜负判定，附单元测试。
2. **内容数据**：6 个职业；约 40 张卡牌，分为小机会、大机会、市场波动、意外支出、人生事件。
3. **数值平衡**：写脚本用几种固定策略各跑上千局，调整数值，使胜率和局长落在目标区间。
4. **界面**：报表面板、事件卡与决策按钮、现金流向动画、手机宽度适配。
5. **复盘页**：对局结束后展示净资产与被动收入曲线，标出关键决策。
6. **收尾**：存档、新手引导、使用说明。

每一步单独提交。第 1–3 步完成后即可在命令行里验证规则是否成立，再做界面。
