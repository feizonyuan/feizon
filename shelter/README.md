# 避难所：不再出门

一个原创的俯视角像素风生存经营游戏，面向大学生。你是一个小避难所的值班员：
白天爬梯子出门，在废墟里搜刮物资、躲开野狗，天黑前赶回来；
回到避难所后建造能自己产粮的设施，睡一觉过一天。
**目标是让避难所每天的自产量不低于消耗量，并且不欠粮，从此不必再出门。**

游戏过程中不出现财务术语。玩家先亲身经历现金流、资产、负债、利息和应急储备，
每局结束后的结算页再把这一局翻译回现实。

画面全部用代码绘制，没有使用任何外部图片素材。

## 运行

游戏是纯静态网页，没有运行时依赖。启动一个本地服务器后打开 <http://localhost:4173>：

```bash
npm run serve
```

运行引擎测试：

```bash
npm test
```

打包成单个 HTML 文件（输出到 `dist/shelter.html`，需要能运行 `npx esbuild`）：

```bash
npm run bundle
```

## 操作

- **走动**：手机上按住屏幕拖动；电脑上用方向键或 WASD。
- **互动**：走到东西旁边，点右下角的按钮，或按空格键、E 键、回车键。

## 玩法

### 避难所里

| 东西 | 作用 |
|---|---|
| 床 | 睡觉，结束这一天。当晚所有人吃饭，设施产粮，欠粮计息 |
| 老周 | 根据眼下的局面给一句提醒 |
| 对讲机 | 向隔壁据点借粮、还粮，每天利息一成 |
| 箱子堆 | 看账本：存粮、每天自产、每天消耗、欠粮 |
| 梯子 | 出门 |
| 地上的虚线框 | 建造设施，共 9 个位置。走到建好的设施旁可以拆卖 |

在避难所里时间不会流逝，可以慢慢想。

### 外面的废墟

- 时间只在外面流逝，从清晨到天黑约 55 秒。天黑时还没回来会摔伤，躺 2 天。
- 走到箱子、废车、集装箱旁边搜刮，东西先进背包。背包满了要回避难所放下，一天可以跑多趟。
- 搜过的地方要过两三天才会重新有东西。
- 顺着公路越往右走，东西越多，野狗也越多、越快。被咬到会丢掉背包里一半的东西，躺 3 天。
- 养伤期间不能出门，只能睡觉过天，口粮照吃。

| 区域 | 每处能搜到 | 野狗 |
|---|---|---|
| 近处 | 1–2 | 没有 |
| 中段 | 2–4 | 3 只，跑得比你慢 |
| 深处 | 4–7 | 6 只，跑得快，看得远 |

只搜近处的话，平均每天到手的不够每天吃的 10 份。想攒下东西，就得往远处走。

### 每晚结算

加自产，减口粮和维护，欠粮滚一成利息，超过 30 的存粮有一部分变质，
第二天早晨可能发生一件事（商队、掠夺者、病害、有人敲门等）。

- 存粮为负时进入“断粮”：可以向隔壁赊粮（记账多五成），或按废铁价拆卖设施；两样都做不到，避难所就撑不下去。
- 欠粮超过 60 时，隔壁据点会拆走你最值钱的设施抵债。
- 每 12 天的最后 3 天是寒冬：外面能搜到的东西变少，农场减产，设施打七折。

## 概念对应

| 游戏里 | 现实里 |
|---|---|
| 亲自出门搜刮，受伤就停工 | 工资（主动收入） |
| 每天吃掉的物资 | 生活开支 |
| 水培农场、净水器、太阳能板、交易站 | 资产（被动收入） |
| 装甲车：背包更大，但每天烧油 | 看着像资产的负债 |
| 向隔壁据点借粮，每天一成利息 | 分期、网贷 |
| 断粮时赊粮，记账多五成 | 走投无路时的高息贷款 |
| 断粮时按废铁价拆卖设施 | 急用钱时贱卖资产（流动性） |
| 存粮放久了变质 | 通货膨胀 |
| 留存粮应对受伤 | 应急储备金 |
| 去深处搜刮：拿得多，也可能被咬 | 高风险高收益 |
| 围墙 | 保险 |
| 农场遇病害全部停产 | 收入来源单一的风险 |
| 寒冬时设施七折 | 市场低迷时的买入机会 |
| “稳赚”的商队 | 保本高收益骗局 |
| 收留幸存者 | 收入涨了，开支也涨 |

## 结算页

- 失败时给出死因（共六种：欠粮、周转不开、赌得太大、受骗、只靠搜刮、没留存粮），
  说明游戏里发生了什么、现实里对应什么、下一局怎么改。
- 通关时把避难所的账本翻译成现实中的收入、开支、资产和负债。
- 两种结局都附带“自产与消耗”“仓库存粮”两张走势图、整局总账，以及这一局碰到的事物与现实概念的对照。

## 目录

```
index.html             入口
src/engine/engine.js   财务规则引擎：act(state, action) 返回新状态，不修改原状态
src/game/world.js      地图生成、碰撞、野狗、背包与搜刮的数值
src/game/sprites.js    全部像素画（用代码绘制）
src/data/              设施、事件、死因文案、概念对照
src/ui/app.js          主程序：操控、镜头、绘制、对话与抽屉
src/ui/report.js       结算页
src/ui/advisor.js      老周的提醒
scripts/bundle.js      打包单文件
scripts/simulate.js    旧版规则的策略模拟（见下）
tests/                 引擎测试
```

财务数值在 `src/engine/engine.js` 的 `RULES` 和 `src/data/` 里，
地图和搜刮的数值在 `src/game/world.js` 的 `WORLD` 里。
进度在每天早晨保存到浏览器的 `localStorage`；中途退出，当天要重新过。
地址以 `#debug` 结尾时，内部状态会挂在 `window.__shelter` 上，供自动化测试使用。

## 现状与不足

- 引擎有 27 个单元测试。画面和流程用无头浏览器自动走过：出门、搜刮、被咬、养伤、建造、睡觉、断粮、失败结算、通关结算。
- **搜刮收益、野狗速度、一天的长度这些数值是估算的，没有经过真人试玩校准。** 难度可能偏易或偏难。
- `scripts/simulate.js` 模拟的是改版前“每回合选一个动作”的抽象规则，不反映现在在地图上搜刮的实际收益，只能用来检查财务规则本身。
- 引擎里保留了三个章节的配置，但现在的游戏只使用规则最全的第三章，没有分章教学。
- 没有音效和音乐。
