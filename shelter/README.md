# 避难所：不再出门

一个原创的单人网页生存经营游戏，面向大学生。你是一个小避难所的负责人，
每周所有人都要吃喝，物资靠你亲自出门搜刮。
**目标是让避难所的自产量不低于消耗量，并且不欠粮，从此不必再出门。**

游戏里不出现财务术语。玩家在玩的过程中体验现金流、资产、负债、应急储备和利息，
每局结束后的死因报告再把这一局翻译回现实。

## 概念对应

| 游戏里 | 财务概念 |
|---|---|
| 亲自出门搜刮，受伤就停工 | 主动收入 |
| 每周吃掉的物资 | 月支出 |
| 水培农场、净水器、太阳能板、交易站 | 资产（被动收入） |
| 装甲车：搜刮更多，但每周烧油 | 负债 |
| 收留幸存者 | 收入涨了，支出也涨 |
| 向隔壁据点借粮，每周 10% 利息 | 高息消费贷、分期 |
| 存粮超过 30 的部分会变质 | 通货膨胀 |
| 留存粮应对受伤和寒冬 | 应急储备金 |
| 围墙 | 保险 |
| 农场遇病害全部停产 | 分散投资 |
| 拆卖设施只值半价 | 流动性 |
| 寒冬时设施七折 | 市场周期 |
| “稳赚”的商队 | 骗局 |

## 为什么面向大学生

- 重点放在大学生最先遇到的问题：分期与网贷、骗局、没有储备金、第一份工资怎么花。
- 一局 10–15 分钟，手机上能玩。
- 死因报告做成可以截图分享的一页。
- 不涉及真实金钱，不推荐任何理财产品。

## 规则概要

- 一回合是一周。**出门搜刮**或**留守**会推进一周；建造、拆卖、借粮、还粮不耗时间。
- 稳妥搜刮收获少、很少受伤；深入搜刮收获多，但有 35% 的概率受伤并停工两周。
- 每周结算：加自产，减消耗，欠粮计息，超额存粮变质，然后可能触发一个事件。
- 每 12 周的最后 3 周是寒冬。
- 物资为负即死亡。欠粮超过上限时，设施会被拆走抵债；没有设施可抵则死亡。

全部数值在 `src/engine/engine.js` 的 `RULES` 和 `src/data/` 里。

## 目录

```
src/engine/engine.js   规则引擎，act(state, action) 返回新状态
src/data/              设施、事件、死因文案
```

## 当前数值下的模拟结果（每种策略 2000 局）

| 策略 | 通关 | 死亡 | 平均通关周数 |
|---|---|---|---|
| 只搜刮不建设 | 0% | 8% | 其余 92% 撑满 80 周仍未脱身 |
| 留 20 存粮再建设 | 94% | 6% | 29.5 |
| 全部投入不留粮 | 78% | 22% | 18.3 |
| 不留粮且深入搜刮 | 50% | 50% | 11.6 |
| 开局借满 | 94% | 6% | 29.9 |

风险越高通关越快、死亡率也越高，这一点符合设计意图。已知的两个问题：

- 借粮策略和稳健策略结果几乎一样，借粮的风险没有体现出来。
- 稳健策略耗时偏长，29 周对一局来说太久。
