# 避难所：不再出门

一个原创的单人网页生存经营游戏，面向大学生。你是一个小避难所的负责人，
每周所有人都要吃喝，物资靠你亲自出门搜刮，而附近的废墟越搜越空。
**目标是让避难所每周的自产量不低于消耗量，并且不欠粮，从此不必再出门。**

游戏过程中不出现财务术语。玩家先亲身经历现金流、资产、负债、利息和应急储备，
每局结束后的结算页再把这一局翻译回现实。

## 运行

游戏是纯静态网页，没有运行时依赖。启动一个本地服务器后打开 <http://localhost:4173>：

```bash
npm run serve
```

运行引擎测试：

```bash
npm test
```

用固定策略批量模拟，查看各章的胜率和局长：

```bash
npm run simulate
```

打包成单个 HTML 文件（输出到 `dist/shelter.html`，需要能运行 `npx esbuild`）：

```bash
npm run bundle
```

## 玩法

- 一回合是一周。**附近搜刮**、**深入废墟**或**留守**会过完这一周；建造、拆卖、借粮、还粮不花时间。
- 附近搜刮收获少，很少受伤；深入废墟收获多，但有 35% 的概率受伤并停工三周。
- 每周结算：加自产，减口粮和维护，欠粮滚一成利息，超过 30 的存粮有一部分变质，然后可能发生一件事。
- 存粮为负时进入“断粮”：可以向隔壁赊粮（记账多五成），或按废铁价拆卖设施；两样都做不到，避难所就撑不下去。
- 欠粮超过 60 时，隔壁据点会拆走你最值钱的设施抵债。

### 三章

每章只多引入一组规则，通关后解锁下一章。

| 章 | 新增内容 |
|---|---|
| 1 自给 | 搜刮、受伤、水培农场、净水器、设备故障 |
| 2 赊账 | 借粮与利息、掠夺者、围墙、“稳赚”的商队 |
| 3 寒冬 | 每 12 周有 3 周寒冬、太阳能板、交易站、装甲车、病害、收留幸存者 |

### 概念对应

| 游戏里 | 现实里 |
|---|---|
| 亲自出门搜刮，受伤就停工 | 工资（主动收入） |
| 每周吃掉的物资 | 生活开支 |
| 水培农场、净水器、太阳能板、交易站 | 资产（被动收入） |
| 装甲车：搜刮更多，但每周烧油 | 看着像资产的负债 |
| 向隔壁据点借粮，每周一成利息 | 分期、网贷 |
| 断粮时赊粮，记账多五成 | 走投无路时的高息贷款 |
| 断粮时按废铁价拆卖设施 | 急用钱时贱卖资产（流动性） |
| 存粮放久了变质 | 通货膨胀 |
| 留存粮应对受伤 | 应急储备金 |
| 围墙 | 保险 |
| 农场遇病害全部停产 | 收入来源单一的风险 |
| 寒冬时设施七折 | 市场低迷时的买入机会 |
| “稳赚”的商队 | 保本高收益骗局 |
| 收留幸存者 | 收入涨了，开支也涨 |

### 结算页

- 失败时给出死因（共六种：欠粮、周转不开、赌得太大、受骗、只靠搜刮、没留存粮），
  说明游戏里发生了什么、现实里对应什么、下一局怎么改。
- 通关时把避难所的账本翻译成现实中的收入、开支、资产和负债。
- 两种结局都附带“自产与消耗”“仓库存粮”两张走势图、整局总账，以及这一局碰到的事物与现实概念的对照。

## 目录

```
index.html             入口
src/engine/engine.js   规则引擎：act(state, action) 返回新状态，不修改原状态
src/data/              章节、设施、事件、死因文案、概念对照
src/ui/                界面：app.js（画面与交互）、report.js（结算页）、advisor.js（提示）、styles.css
scripts/simulate.js    固定策略批量模拟
scripts/bundle.js      打包单文件
tests/                 引擎测试
```

全部数值在 `src/engine/engine.js` 的 `RULES` 和 `src/data/` 里。
随机数带种子，状态里保存了随机数位置，同一种子和同样的操作会得到同样的对局。
进度保存在浏览器的 `localStorage`。

## 数值现状

每种策略每章模拟 2000 局的结果（通关率 / 平均通关周数）：

| 策略 | 第 1 章 | 第 2 章 | 第 3 章 |
|---|---|---|---|
| 只搜刮不建设 | 0% | 0% | 0% |
| 留 20 存粮再建设 | 92% / 26 周 | 84% / 30 周 | 86% / 31 周 |
| 全部投入不留粮 | 88% / 17 周 | 90% / 20 周 | 87% / 22 周 |
| 不留粮，断粮就赊 | 88% / 17 周 | 96% / 20 周 | 95% / 21 周 |
| 不留粮且只走深入废墟 | 56% / 13 周 | 86% / 17 周 | 77% / 18 周 |

已经成立的结论：只靠搜刮永远无法脱身；冒险深入通关更快，但失败也更多。

已知的不足：

- 第 2、3 章里，“不留存粮、断粮就赊”的机械策略胜率高于“留 20 存粮”。
  也就是说，赊粮的代价对一个立刻还粮的玩家来说还不够重，应急储备的价值只在第 1 章体现得充分。
- 模拟用的是固定策略的脚本，不代表真人的体验。数值没有经过真人试玩校准。
