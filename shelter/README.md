# 末日躺平指南

一个原创的俯视角像素风生活模拟游戏，面向大学生。

末日后第三年，你是幸存者营地里租铁皮屋住的躺平青年。房东每五天收一次租，物价会涨，
除此之外没有任何目标：可以种菜、钓鱼、翻废墟、打零工，也可以喝奶茶、打游戏、躺吊床。
**没有通关，也没有失败。** 每次交租时，游戏会告诉你过去几天你过成了什么样
（躺平大师、月光族、卷王、负债青年、财富自由等），并说明它在现实里对应什么。

画面全部用代码绘制，音效用浏览器合成，没有使用任何外部素材。

> 目录名 `shelter/` 是这个项目早期版本留下的，游戏本身已经改名。

## 运行

纯静态网页，没有运行时依赖。启动本地服务器后打开 <http://localhost:4173>：

```bash
npm run serve
```

运行规则测试：

```bash
npm test
```

打包成单个 HTML 文件（输出到 `dist/shelter.html`，需要能运行 `npx esbuild`）：

```bash
npm run bundle
```

## 操作

| | 电脑 | 手机 |
|---|---|---|
| 走动 | WASD 或方向键 | 按住屏幕拖动 |
| 选物品 | 数字键 1–0 | 点屏幕下方的格子 |
| 对面前一格动手 | 空格、E、回车，或用鼠标点那一格 | 右下角的按钮 |
| 看账本 | Tab，或右上角“账本” | 右上角“账本” |
| 暂停 | Esc | 右上角菜单 |

手里拿着什么，决定了“动手”是做什么：拿锄头是翻地，拿种子是播种，拿水壶是浇水，
拿鱼竿对着水是钓鱼，拿吃的是吃掉。面对人、门、床、设备时则是和它互动。

## 小世界

一张连续的地图（72×46 格），外加铁皮屋的室内。

| 地方 | 能做什么 |
|---|---|
| 自家院子 | 围栏里的菜地可以翻地种菜；四块空地可以添置设备；吊床可以躺；进屋睡觉 |
| 营地广场 | 找房东老周打零工；在阿梅的小卖部买卖；在小桃的摊上喝奶茶；找金老板借钱；看公告栏上的账本 |
| 池塘 | 钓鱼：甩竿后等感叹号出现，马上收竿 |
| 树林 | 摘野莓、采蘑菇，两天后重新长出来 |
| 废墟 | 翻箱子、废车、冰箱，找废铁、罐头和电池。深处东西更值钱，但有野狗 |

一天从 6:00 到 24:00，约 170 秒。回屋上床睡觉就到第二天；熬到半夜会倒下，第二天体力减半。

## 规则

三个状态条：

- **体力**：干活要花，睡觉恢复。饿着睡只恢复六成。
- **饱食**：每天掉 45，吃东西补回来。
- **心情**：每天掉 8，搬砖也掉。低于 30 时干活多费五成体力。喝奶茶、打游戏、躺吊床能补。

钱的进出：

| 进 | 出 |
|---|---|
| 搬砖：4 小时、40 体力，挣 34，一天一次 | 房租：每 5 天 60 |
| 卖菜、鱼、野货、废铁、电池 | 吃的：罐头 9 一个 |
| 设备每天早上自动进账 | 种子、奶茶、游戏机、电动车 |
| | 欠款利息：每天半成，利滚利 |

能自己赚钱的设备（放在院子的空地上，价格随物价上涨）：

| 设备 | 价格 | 每天进账 |
|---|---|---|
| 雨水收集器 | 120 | 8 |
| 鸡窝 | 220 | 16 |
| 太阳能充电站 | 380 | 30 |
| 自动售货机 | 650 | 55 |

其他规则：

- 每次交租后物价上涨 4%，房租、商品、卖价、设备收入都跟着涨，手里的现金不会涨。
- 交不起租时，差的部分加两成记成欠款。
- 欠款超过 450，金老板会搬走院子里最值钱的设备抵债。
- 游戏机每天电费 3，电动车每天充电 5。
- 被野狗咬到要花掉身上一成半的钱包扎。
- **财富自由**：设备每天赚的钱不低于“每天最少要花的钱”（房租摊到每天 + 两顿饭 + 电费），并且不欠债。达成后游戏照常继续。

## 这个游戏想让人体会到的事

| 游戏里 | 现实里 |
|---|---|
| 搬砖 | 工资：稳定，但一停就没有 |
| 种菜、钓鱼、翻废墟 | 自己做点小生意：赚得多，也更费心力 |
| 院子里的设备 | 能产生收入的资产 |
| 游戏机、电动车 | 买完还要持续花钱的消费品 |
| 奶茶、吊床 | 娱乐开支：不是浪费，但要有数 |
| 金老板 | 网贷、分期 |
| 物价每五天涨一次 | 通货膨胀 |
| 被狗咬的包扎费 | 意外支出，以及为什么要留应急的钱 |
| 每次交租时的评语 | 回头看自己的收支结构 |

## 目录

```
index.html            入口
src/game/state.js     规则：物品、种植、钱、房租、借贷、每日结算、生活评语（不涉及画面，可单独测试）
src/game/map.js       地图布局：院子、广场、池塘、树林、废墟、室内
src/game/art.js       全部像素画（用代码绘制）
src/ui/app.js         主程序：操控、互动、对话、绘制、音效
src/ui/icons.js       界面上的线条图标
src/ui/styles.css     首页、面板和对话框的样式
scripts/bundle.js     打包单文件
tests/state.test.js   规则测试
```

进度自动保存到浏览器的 `localStorage`（每天早晨、每次买卖后，以及每 20 秒）。
地址以 `#debug` 结尾时，内部状态会挂在 `window.__game` 上，供自动化测试使用。

## 现状与不足

- 规则有 17 个单元测试。画面和流程用无头浏览器自动走过一遍：种地、买卖、钓鱼、进屋睡觉、买设备、交租评语、手机竖屏。
- **数值没有经过真人试玩校准。** 各种活动的收益、一天的长度、物价上涨的速度都是估算的。
- 美术是用代码画的，比不上手绘素材；角色只有行走动画，没有挥锄头、浇水的动作。
- 营地里的四个人只会站在原地，没有日程和好感度。
- 没有背景音乐，没有天气和季节，没有储物箱，背包只有 10 格。
- 铁皮屋内部在电脑上不会铺满屏幕，周围用屋顶纹理填充。
