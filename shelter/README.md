# 躺平计划：现金流物语（暂定名）

一个原创的俯视角像素风生活模拟游戏，面向大学生，目前只做电脑版（键盘加鼠标）。
这是第一版，范围是“一条街 + 四处室内”，内容覆盖设计文档里的前三个月，并补了两种资产让后半段有事可做。

城市边上的老街。你二十出头，租着一套老旧的小套间，没有文凭、手艺和家底，兜里 300 块，五天后要交 400 的房租。
你唯一能拿去换钱的是自己的时间：每天醒着 16 个钟头，打工、上课、吃饭、歇着都要从里面扣。

游戏没有“奋斗”或“躺平”的路线可选，也不给玩家贴标签。每个账单日它只做一件事：
把这个月的钱从哪来、到哪去，以及这个月的时间花在了哪儿，原样摆出来。

**目标**：让不干活也会进来的钱，连续三个账单周期盖过不得不花的钱，并且不欠债。到那时，去不去上班由你决定。

画面全部用代码绘制，音效用浏览器合成，没有使用任何外部素材。

> 目录名 `shelter/` 是这个项目早期版本留下的。

## 运行

纯静态网页，没有运行时依赖。启动本地服务器后打开 <http://localhost:4173>：

```bash
npm run serve
```

运行规则测试：

```bash
npm test
```

用几种固定的过法各过若干个月，查看数值曲线：

```bash
npm run simulate
```

打包成单个 HTML 文件（输出到 `dist/shelter.html`，需要能运行 `npx esbuild`）：

```bash
npm run bundle
```

## 这条街

| 地方 | 能做什么 |
|---|---|
| 幸福公寓（家） | 睡觉、做饭、洗澡、翻闲书、在沙发上歇着；学成后在书桌上写教程 |
| 便利店（可进） | 找老板买便当、食材，合伙摆二手自动售货机 |
| 阿福快餐（可进） | 找店长上班。阿强站在店门口 |
| 一口甜奶茶 | 在街边窗口买，花钱快速回心力。莉莉坐在门口 |
| 推销员的摊子 | 零首付的分期手机和电动车 |
| 社区夜校（可进） | 找老师或坐到课桌前上课；学完后在公告栏接维修单 |
| 公园 | 长椅免费歇着；老陈在池塘边钓鱼，一天教一课 |
| 公交站旁的空地 | 第二个月起，手里有钱时“财富导师”会出现 |
| 巷子里的床位房 | 破产后住的地方 |

今天有事的地方和有新话要说的老陈，头顶会冒一个感叹号。
路人遇到你会停下等；车是实的，走不进车身，你站在车前它会停。

## 规则

**时间**：一天从 7:00 到 23:00，约 190 秒。时钟一直在走，打工和上课一次扣掉几个钟头。到 23:00 会被送回去睡。每 5 天是一个账单周期（“月”）。

**三个状态**

- 体力：干活要花，睡觉恢复。饿着睡只恢复到 65。
- 饱食：醒着每小时掉 3，一顿饭补 50。低于 20 时干活多费三成体力。
- 心力：打工和上课会掉，每晚自然恢复 8。低于 30 时走得慢，上不了课，也写不了教程。

**每天能做的事**

| 事 | 时间 | 钱 | 体力 | 心力 |
|---|---|---|---|---|
| 快餐店打一班工 | 4 小时 | +60，出餐快另有 6 或 12 小费 | −30 | −12，手忙脚乱再 −4 |
| 夜校上一节课（共 6 节） | 2 小时 | −30 | −10 | −6 |
| 接一单维修（学完后，一天最多 3 单） | 2 小时 | +90，修得利索 +15，修坏 −20 | −22 | −5 |
| 写教程（学完后，5 次写完一份，最多两份） | 2 小时 | | −8 | −4 |
| 便当 | 半小时 | −15 | | |
| 自己做饭（食材 5 元一份） | 1 小时 | | | +4 |
| 奶茶 | 半小时 | −18 | | +25 |
| 公园长椅、家里的沙发 | 1 小时 | | | +10 |
| 翻闲书 | 1 小时 | | | +7 |
| 洗澡（一天一次） | 半小时 | | | +6 |
| 和老陈钓鱼（第三课之后） | 2 小时 | | | +22 |

**小操作**：打工、上课、接维修单时各有一个十来秒的小环节。

- 出餐：照着单子按方向键，14 秒内出完六单。
- 听课和找故障：游标来回扫，扫进绿色那一段时按空格，一共五次。

成绩只影响小费、挨骂和课程进度，不影响基础收入。每次都可以点“不玩，直接干完”，按中等成绩算。

**每天的事**：从第二天起，每天早上抽一件。约三成是普通的一天，其余包括：
临期便当半价、快餐店缺人多给钱、下雨（长椅和钓鱼用不了）、阿强请客、莉莉请奶茶、
夜校公开课免学费、有人急修给双倍、老陈钓到大鱼、楼里停电（做不了饭）。

**账单日**：被动收入进账；房租、分期、充电保养从现金里扣；欠款的利息并入欠款。
现金不够时自动用闪电贷补上，信用下降。

**往里流钱的东西**

| | 代价 | 每个账单日 | 特点 |
|---|---|---|---|
| 二手自动售货机（最多 6 台） | 500 元 | +120 | 回本快，急用钱时只能卖 250 |
| 维修教程（最多 2 份） | 10 小时，不花钱 | +90 | 用时间做出来的 |
| 指数基金 | 100 元起 | 市值的 3% | 价钱每月在 −6% 到 +8% 之间波动，随时能卖 |

**往外流钱的东西**

- 分期手机：零首付，心力立刻 +30，之后每晚多恢复 3；每个账单日 −90，共 6 期。
- 电动车：零首付，走路快 45%；车贷每个账单日 −150 共 8 期，另有充电保养 −20，还完贷也要一直付。
- 闪电贷：额度是信用分的 8 倍，每个账单日利息一成。

**意外**

- 生病：第一个月不会无缘无故生病；之后平时每天 2%。任何时候一天干满 8 小时且体力见底是 15%，干满 10 小时是 35%。医药费 260，没钱就自动借。
- 涨租：第三个月起房租涨 15%。
- 稳盈宝：号称月息三成。第一个账单日准时“分红”，第二个账单日本金全没。

**认知**：和老陈聊天会提高。它不替玩家做判断，只决定能看到多少信息：

- 第一课：拿到旧账本，手机里出现两张表。在此之前，账单日只告诉你“交完房租还剩多少”。
- 第二课之后：推销员的商品会显示总共要付多少。
- 第五课之后：能看到稳盈宝的底细。

**破产是软着陆**：账单日现金不够、闪电贷也借不到时，分期的东西被收走，人搬去床位房
（月租 200，睡不好）。游戏继续，攒够 300 押金可以搬回去。

**家里会跟着日子变**：窗外的天色和屋里的光随时间变化。拿到账本后它摆在桌上；
上过课桌上多一本教材；学成后墙上挂结业证、门口放工具箱；买了食材冰箱前有购物袋；
分期的手机在床头柜上；电动车头盔在门口；心力低时床边堆着泡面桶，绿植也蔫了。

**画面的颜色**：鲜艳程度跟着心力和“被动收入盖住固定开销的比例”连续变化。开局是灰的，赎回时间后完全恢复。

## 数值现状

每种过法模拟 200 遍、8 个月，小操作一律按“直接干完”算。
身家 = 现金 + 能卖的东西 − 欠款，表里是每月底的平均值。

| 过法 | 第 1 月 | 第 3 月 | 第 5 月 | 第 8 月 | 结果 |
|---|---|---|---|---|---|
| 打两班工，吃便当，喝奶茶解压 | 397 | 500 | 525 | 590 | 每月剩二三十 |
| 打两班工，吃便当，不花钱歇着 | 451 | 661 | 790 | 1017 | 每月剩八十左右 |
| 打两班工，自己做饭 | 485 | 760 | 949 | 1276 | 每月剩一百出头 |
| 打三班工，吃便当 | 303 | 204 | 72 | 159 | 41% 累病到破产 |
| 做饭 + 夜校，学成后接维修单 | 329 | 1995 | 3763 | 6428 | 学成后每月剩近九百 |
| 再加上攒钱买售货机 | 329 | 1707 | 4270 | 9096 | 全部赎回时间，平均第 5.5 个月 |
| 再加上写教程 | 329 | 1794 | 4711 | 10081 | 全部赎回时间，平均第 5.5 个月 |
| 不买售货机，余钱全买基金 | 334 | 2072 | 4084 | 7466 | 8 个月内没有人赎回时间 |

这些是固定策略的脚本算出来的，不代表真人的体验。

## 目录

```
index.html            入口
src/game/state.js     规则：时间、状态、收支、资产、负债、每天的事、账单日（不涉及画面，可单独测试）
src/game/map.js       地图布局：街道、家、便利店、快餐店、夜校教室
src/game/art.js       街道上的像素画（用代码绘制）
src/game/roomart.js   家里的像素画
src/game/shopart.js   三家店里的像素画
src/game/story.js     老陈的六课，阿强、莉莉的台词，开场白
src/ui/app.js         主程序：操控、互动、对话、手机、绘制、音效
src/ui/minigame.js    出餐、听课、找故障三个小操作
src/ui/icons.js       界面上的线条图标
src/ui/styles.css     首页、面板和对话框的样式
scripts/simulate.js   固定过法的批量模拟
scripts/bundle.js     打包单文件
tests/state.test.js   规则测试
```

进度自动保存到浏览器的 `localStorage`（每次花时间做事之后、每天早晨，以及每 20 秒）。
规则改动后旧存档不兼容，会被丢弃。
地址以 `#debug` 结尾时，内部状态会挂在 `window.__game` 上，供自动化测试使用。

## 没有做的和已知不足

按约定留到后续版本：

- 设计文档的第三、四阶段：股票、银行贷款、杠杆买公寓和洗衣房，以及配套的空置和加息事件。
- 阿强和莉莉的完整命运线、好感度。现在他们只有随月份变化的几句话和偶尔请客。
- 税、失业事件、“加盟店”和“成功学课程”两种骗局。
- 账单日的水管动画、背景音乐。
- 手机版：触屏代码留着，但不再维护，界面也只按电脑调整。

已知不足：

- **数值和小操作的难度没有经过真人试玩校准。** 只用脚本模拟和自动化点击验证过。
- 两个小操作（听课和找故障）用的是同一套玩法，只是换了文字。
- “写教程”和“只买基金”两条路单独走都不够赎回时间，实际仍以售货机为主。
- 奶茶店和床位房没有室内；洗衣机、衣柜等家具只能看一眼。
- 角色只有行走动画；店里的人只会站在原地。
- 下雨天老陈仍站在池塘边，只是不再甩竿。
- 美术是用代码画的，和手绘素材仍有差距。
