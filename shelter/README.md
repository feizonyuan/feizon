# 躺平计划：现金流物语（暂定名）

一个原创的俯视角像素风生活模拟游戏，面向大学生。这是第一版，范围是“出租屋 + 一条街”，内容覆盖设计文档里的前三个月。

城市边上的老街。你二十出头，住十平米出租屋，没有文凭、手艺和家底，兜里 300 块，五天后要交 400 的房租。
你唯一能拿去换钱的是自己的时间：每天醒着 16 个钟头，打工、上课、吃饭、歇着都要从里面扣。

游戏没有“奋斗”或“躺平”的路线可选，也不给玩家贴标签。每个账单日它只做一件事：
把这个月的钱从哪来、到哪去，以及这个月的时间花在了哪儿，原样摆出来。

**目标**：让不干活也会进来的钱，连续三个账单周期盖过不得不花的钱，并且不欠债。到那时，去不去上班由你决定。

画面全部用代码绘制，音效用浏览器合成，没有使用任何外部素材。

> 目录名 `shelter/` 是这个项目早期版本留下的。

## 运行

纯静态网页，没有运行时依赖。启动本地服务器后打开 <http://localhost:4173>：

```bash
npm run serve
```

运行规则测试：

```bash
npm test
```

用几种固定的过法各过若干个月，查看数值曲线：

```bash
npm run simulate
```

打包成单个 HTML 文件（输出到 `dist/shelter.html`，需要能运行 `npx esbuild`）：

```bash
npm run bundle
```

## 这条街

| 地方 | 能做什么 |
|---|---|
| 幸福公寓（出租屋） | 睡觉；灶台做饭；桌前发呆；冰箱、衣柜、床头柜、晾衣架、纸箱都可以看一眼 |
| 便利店 | 买便当、买食材；和老板合作摆二手自动售货机 |
| 阿福快餐 | 打小时工。阿强站在门口 |
| 一口甜奶茶 | 花钱快速回心力。莉莉坐在门口 |
| 推销员的摊子 | 零首付的分期手机和电动车 |
| 社区夜校 | 上家电维修课；学完后在这里接维修单 |
| 公园 | 长椅免费歇着；老陈在池塘边钓鱼，一天教一课 |
| 公交站旁的空地 | 第二个月起，手里有钱时“财富导师”会出现 |
| 巷子里的床位房 | 破产后住的地方 |

马路上有车，人行道上有路人，它们只是布景。车看到你在前面会停。

## 规则

**时间**：一天从 7:00 到 23:00，约 190 秒。时钟一直在走，打工和上课一次扣掉几个钟头。到 23:00 会被强制送回去睡。每 5 天是一个账单周期（“月”）。

**三个状态**

- 体力：干活要花，睡觉恢复。饿着睡只恢复到 65。
- 饱食：每天掉 50，一顿饭补 50。
- 心力：打工和上课会掉，每晚自然恢复 8。低于 30 时走得慢，而且上不了课。

**每天能做的事**

| 事 | 时间 | 钱 | 体力 | 心力 |
|---|---|---|---|---|
| 快餐店打一班工 | 4 小时 | +60 | −30 | −12 |
| 夜校上一节课（共 8 节） | 2 小时 | −30 | −10 | −6 |
| 接一单维修（学完后，一天最多 3 单） | 2 小时 | +80 | −22 | −5 |
| 便当 | 半小时 | −15 | | |
| 自己做饭（食材 5 元一份） | 1 小时 | | | +4 |
| 奶茶 | 半小时 | −18 | | +25 |
| 公园长椅 | 1 小时 | | | +10 |
| 和老陈钓鱼（第三课之后） | 2 小时 | | | +22 |

**账单日**：售货机的分成进账；房租、分期、充电保养从现金里扣；欠款的利息并入欠款。
现金不够时自动用闪电贷补上，信用下降。

**往里流钱的东西**

- 二手自动售货机：600 元一台，每个账单日 +110，最多 6 台。急用钱时只能卖 300。

**往外流钱的东西**

- 分期手机：零首付，心力立刻 +30，之后每晚多恢复 3；每个账单日 −90，共 6 期。
- 电动车：零首付，走路快 45%；车贷每个账单日 −150 共 8 期，另有充电保养 −20，还完贷也要一直付。
- 闪电贷：额度是信用分的 8 倍，每个账单日利息一成。

**意外**

- 生病：平时每天 2% 的可能；一天干满 8 小时且体力见底时 15%；干满 10 小时 35%。医药费 260，没钱就自动借。
- 涨租：第三个月起房租涨 15%。
- 稳盈宝：号称月息三成。第一个账单日准时“分红”，第二个账单日本金全没。

**认知**：和老陈聊天会提高。它不替玩家做判断，只决定能看到多少信息：

- 第一课：拿到旧账本，手机里出现两张表。在此之前，账单日只告诉你“交完房租还剩多少”。
- 第二课之后：推销员的商品会显示总共要付多少。
- 第五课之后：能看到稳盈宝的底细。

**破产是软着陆**：账单日现金不够、闪电贷也借不到时，分期的东西被收走，人搬去床位房
（月租 200，睡不好）。游戏继续，攒够 300 押金可以搬回去。

**出租屋会跟着日子变**：窗外的天色和屋里的光随时间变化，晚上拉上窗帘、只剩一盏灯。
拿到账本后它摆在桌上；上过课桌上多一本教材；学成后墙上挂结业证、门口放工具箱；
买了食材冰箱前有购物袋；分期的手机在床头柜上；电动车头盔在门口；
心力低于 30 时床边堆着泡面桶，窗台的绿植也蔫了，心力高时它会开花。

**画面的颜色**：鲜艳程度跟着心力和“被动收入盖住固定开销的比例”连续变化。开局是灰的，赎回时间后完全恢复。

## 数值现状

每种过法模拟 200 遍、10 个月，每月底的“现金减欠款”平均值：

| 过法 | 第 1 月 | 第 3 月 | 第 6 月 | 第 10 月 | 结果 |
|---|---|---|---|---|---|
| 打两班工，吃便当，喝奶茶解压 | 351 | 334 | 289 | 156 | 越过越少 |
| 打两班工，吃便当，去公园坐着 | 405 | 514 | 632 | 739 | 每月剩几十 |
| 打两班工，自己做饭 | 445 | 644 | 907 | 1211 | 每月剩一百左右 |
| 打三班工，吃便当 | 267 | 96 | −35 | 101 | 68% 累病到破产 |
| 做饭 + 夜校，学成后接维修单 | 295 | 993 | 2443 | 4352 | 学成后每月剩近五百 |
| 做饭 + 夜校 + 攒钱买售货机 | 295 | 475 | 950 | 4665 | 98% 赎回时间，平均第 8.3 个月 |

这些是固定策略的脚本算出来的，不代表真人的体验。

## 目录

```
index.html            入口
src/game/state.js     规则：时间、体力、心力、收支、资产、负债、账单日（不涉及画面，可单独测试）
src/game/map.js       地图布局：一条街和出租屋
src/game/art.js       街道上的像素画（用代码绘制）
src/game/roomart.js   出租屋里的像素画
src/game/story.js     老陈的六课，阿强、莉莉的台词，开场白
src/ui/app.js         主程序：操控、互动、对话、手机、绘制、音效
src/ui/icons.js       界面上的线条图标
src/ui/styles.css     首页、面板和对话框的样式
scripts/simulate.js   固定过法的批量模拟
scripts/bundle.js     打包单文件
tests/state.test.js   规则测试
```

进度自动保存到浏览器的 `localStorage`（每次花时间做事之后、每天早晨，以及每 20 秒）。
地址以 `#debug` 结尾时，内部状态会挂在 `window.__game` 上，供自动化测试使用。

## 第一版没有做的

按约定留到后续版本：

- 设计文档的第三、四阶段：基金和股票、银行贷款、杠杆买公寓和洗衣房，以及配套的空置和加息事件。
- 阿强和莉莉的完整命运线、好感度。现在他们只有随月份变化的几句话。
- 税、失业事件、“加盟店”和“成功学课程”两种骗局。
- 账单日的水管动画、背景音乐。

做的过程中发现的不足：

- **数值没有经过真人试玩校准。** 只用脚本模拟过。
- 第一版只有售货机一种资产，赎回时间只能靠买满 6 台，路径单一，而且要 8 个月左右（约两小时）。
- 除出租屋外，其他建筑都没有室内，走到门口直接弹出对话。
- 出租屋只有十平米，在电脑上放大到屏幕高度的九成，左右两侧仍是深色砖纹。
- 角色只有行走动画；街上的车和路人只是布景，不能互动。
- 美术是用代码画的，和手绘素材仍有差距。
