# 20岁重启指南 · 抖音竖屏动画

把「邵艾伦 × 孙宇晨」4 小时对谈的博客整理稿，压缩成一支 **约 59 秒的竖屏（1080×1920，60fps）动画**，风格是“轻 HUD 游戏风”：深蓝底 + 荧光黄/青、像素字体、任务进度格、地图迷雾、“QUEST CLEAR!”弹窗。

画面、动效、背景音乐、音效全部用代码生成；旁白用离线中文 TTS 合成。

## 成片

| 文件 | 用途 |
|---|---|
| [`final/reboot-at-20.mp4`](final/reboot-at-20.mp4) | 成片：画面 + 旁白 + 音乐音效，可直接发抖音 |
| [`final/reboot-at-20-novoice.mp4`](final/reboot-at-20-novoice.mp4) | 同一画面，只有音乐音效，**方便在剪映里换配音** |
| [`final/subtitles.srt`](final/subtitles.srt) | 字幕文件（画面里已经烧录了字幕，这个用于剪映配音/对轴） |
| [`final/cover.png`](final/cover.png) | 建议封面帧 |

> **关于配音**：云端环境连不上在线 TTS，旁白是离线模型（标贝女声 FastSpeech2）合成的，能听清，但不如剪映/抖音自带的 AI 配音自然。
> 想要更好的声音：把 `reboot-at-20-novoice.mp4` 导入剪映 →「文本朗读」逐句贴下面的旁白（或导入 `subtitles.srt`），按字幕时间对齐即可。画面节奏是按旁白时间点卡的，每句起点见 `timeline.json`。

## 内容取舍（为什么只讲这 4 条）

原稿 11 条观点，按抖音传播性筛选：

- **保留**：先把自己 AI 化（AI 热点 + 能照做）、买房先看 100 套/先探图（金句好懂）、先自由后财富/别太早用房贷车贷锁死自己（最容易引发评论区讨论）、AI 越强身体越值钱（薄肌/健身话题）。
- **删掉**：Crypto（抖音对虚拟货币内容限流）、价值断点、AI 语料、Small Ego、人生意义（太抽象）。只留“多创造，少消费”做结尾金句。
- 结尾用“你最不同意哪一条？”引导评论，片尾加了“观点仅供参考，不构成任何建议”。

## 技术管线

```
script.json ──> scripts/tts.py（zhtts 离线 TTS）──> audio/lXX.wav + durations.json
                                                     │
                     scripts/build_data.js <─────────┘  按旁白时长生成 timeline.json（唯一时间源）
                     │
                     ├─> src/*.js  Canvas 1080×1920 矢量动画，每帧 4 次子采样做运动模糊
                     │      └─ scripts/render.js：Playwright 无头 Chromium 逐帧截图 → ffmpeg
                     ├─> scripts/audio.py：numpy 合成芯片 BGM + 音效，按事件对齐，人声闪避混音
                     └─> scripts/mux.sh：拼接、-14 LUFS 响度标准化、封装成片 + 无旁白版 + SRT
```

## 复现

```bash
# 0) 字体：从 npm 下载 @fontsource/noto-sans-sc、zcool-qingke-huangyou、press-start-2p 解包到 $FONT_SRC
FONT_SRC=/path/to/unpacked node scripts/fonts.js        # 只拷贝用到的字形分片到 src/fonts/
# 1) 旁白（Python 3.11 venv：tensorflow-cpu==2.15.1 "numpy<2" zhtts）
python scripts/tts.py
# 2) 音频
python3 scripts/audio.py
# 3) 画面（可分段并行；--stills 预览单帧）
node scripts/render.js --from 0 --to 891 --out seg0.mp4
node scripts/render.js --stills 3.6,24.4 --sub 1
# 4) 合成
bash scripts/mux.sh
```
